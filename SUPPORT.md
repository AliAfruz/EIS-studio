# Support

For reproducible bug reports, include:

- EIS Gold Studio version and operating system;
- Python and dependency versions;
- the smallest non-confidential input file that reproduces the problem;
- the selected circuit, weighting, optimizer, bounds, and locked parameters;
- the complete traceback or exported diagnostic report.

Scientific interpretation questions should also describe the cell geometry, reference electrode, perturbation amplitude, DC bias, frequency range, and measurement conditions.
